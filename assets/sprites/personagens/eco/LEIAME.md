# ECO — folha de referência v1 (IA + tratamento, D-039)

`eco_referencia.png`: 2 quadros 48×48, origem nos pés (24, 48). Quadro 0 = de frente, quadro 1 = de perfil (virada para a direita; para a esquerda use `flip_h`). Paleta: tons de âmbar com rampas (D-033: a ECO é âmbar, nunca teal).

Por enquanto é **referência aprovada** pela ART (base da descrição fixa da ECO, pacote 03), não um sprite animado. Para usar já na nave, o quadro 0 serve de holograma parado. O brilho (cintilar, linhas de varredura animadas, mistura aditiva) fica com o DEV, por cima do PNG.
